## ADR-004: Thread-Safe In-Memory Storage & Immutability
### Context
PaymentsRepository used a non-thread-safe `HashMap` inside a singleton Spring `@Repository` and `PaymentResponse` was a mutable JavaBean with boilerplate setters

### Decisions
1. Replaced `HashMap` with `ConcurrentHashMap` in `PaymentsRepository` so that concurrent HTTP requests against the singleton repository are thread-safe.
2. Replaced the `PaymentResponse` class with an immutable Java record to eliminate boilerplate and guarantee immutability after creation.
3. Used the same immutable records for `BankPaymentRequest` and `BankPaymentResponse`.
