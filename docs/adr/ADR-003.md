## ADR-003: Acquiring Bank integration and Error Handling
### Context
The gateway integrates with the acquiring bank simulator and must validate payment requests and gracefully handle upstream failures like a 503 Service Unavailable or network timeouts.

### Decisions
1. Created an HTTP Client for integrating with the Acquiring Bank simulator using Spring's RestTemplate and an externalised bank.simulator.url property, keeping HTTP transport decoupled from PaymentGatewayService.
2. Mapped downstream RestClientException (like the 503's or timeouts) to BankUnavailableException, which we map to a 502 Bad Gateway, without persisting a payment record.
